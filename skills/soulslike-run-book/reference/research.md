# Research

What to gather before a run book is written. Work from the game's wikis (Fextralife, Fandom,
wiki.gg), a trophy roadmap (PowerPyx, PSNProfiles), and a missables checklist; record each
source for the page footer. Search with the game's own nouns once the first source reveals
them.

Counts and lock triggers are where sources drift apart between patches. Confirm each against a
second source. When two disagree, carry both onto the page with a safe instruction ("sources
say 4 or 5 — open all 5"), as the player cannot check mid-run.

Scope everything to the intake answers: DLC content only when DLC is in; NG+ content only as
"comes back in NG+".

## Categories

Fill each, or write "this game has none".

1. **Area graph.** Every area in the order a first run reaches it; for each, the checkpoints by
   their in-game names, the boss or exit, optional and hidden areas with their entrance, and
   points of no return.
2. **Walking order per area.** From the arrival checkpoint to the boss: loot worth stopping
   for, NPCs, shortcuts, side paths, each tied to a landmark the player can see (a named
   checkpoint, a lift, a fog door, a distinctive enemy). This feeds the Navigator; a category
   list without a path cannot.
3. **Locks.** Every event that closes something: boss deaths, area transitions, quest steps
   that fail another quest, hub events, NPC hostility. For each: the trigger, everything it
   closes, and whether a recovery exists.
4. **Quests.** Every NPC questline, step by step with locations, the dialogue answer where one
   matters, the rewards, and the lock that ends it. Note quests that cross areas and quests
   that conflict.
5. **Budgets.** Every capped resource: total per run, each location, what it buys, and the
   full cost of buying everything, so the page can show the budget against the cost.
6. **Forks.** Every one-way choice: both outcomes, what each costs elsewhere, and whether the
   other side returns in NG+.
7. **Build lines.** The game's scaling stats or styles; per line the best weapons with where
   they come from, supporting gear, stat targets and soft caps. Enough to commit one line and
   list the others as reference.
8. **Missable loot.** Unique weapons, gear, spells, key items, merchant stock that moves or
   disappears, each with its lock.
9. **Endings.** Every ending, the decisions and thresholds that select it, where each decision
   happens, and the latest save point that still reaches all of them.
10. **Achievements.** The full list with a missable flag on each, the minimum number of runs,
    the save-backup points that reduce it, and post-game tasks that must precede NG+.

## Completion

Every lock has a trigger. Every budget has a total and a location for each unit. Every
missable in categories 4, 8 and 10 names the lock that closes it. Every area in category 1
has a walking order in category 2.
